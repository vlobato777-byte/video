# Copy del anuncio y mensajes (Meta Ads)

Los textos para el público van en inglés (Canadá y Estados Unidos) y se agrega una versión en francés para Quebec. Lo que está entre `[corchetes]` debe confirmarse antes de publicar (ver [05-pendientes.md](05-pendientes.md)).

> **Regla de oro:** el texto no debe prometer nada que el video o la realidad no respalden. Nada de "all-inclusive", "beachfront", "ocean view", "walk to the beach", "heated pool", "gym" ni "step-free".

## 5. Configuración de mensajes

**Mensaje precargado (WhatsApp) o saludo (Messenger)**
```
Hi! I'm interested in Condo Lua for winter 2027.
Arrival: ___  Departure: ___  Guests: ___
```

**Preguntas frecuentes / ice-breakers (máximo 4)**
1. Is it available January–April 2027?
2. What's the monthly rate?
3. What's included?
4. How far is the beach?

**Respuestas listas para copiar**

*Disponibilidad*
```
Thanks for reaching out! 🌞 To check availability, could you share:
1) arrival and departure dates, 2) number of guests, 3) any pets?
We'll get back to you with availability and the monthly rate.
```

*Qué incluye*
```
The monthly rate includes electricity [up to X kWh/month], water, Wi-Fi and condo fees.
The condo is fully furnished, with an equipped kitchen, a private laundry room (washer & dryer), A/C, parking and a private terrace. Guests can use the shared pool and gardens.
```

*Ubicación (con honestidad: evita reclamos)*
```
Condo Lua is in a gated community in Bucerías, Riviera Nayarit. It's about an 11-minute drive to Bucerías beach (Zona Dorada) and about 25 minutes to Puerto Vallarta airport (PVR). Supermarkets are a short drive away. We recommend having a car.
```

*Tarifa*
```
For January–April 2027 the rate is $[X] USD/month, with a [minimum stay]. [Deposit / payment terms]. Would you like us to hold your dates?
```
